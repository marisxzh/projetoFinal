Fundamentos de Git e GitHub

Projeto Integrador Final do curso do CEFET-MG. Esta página resume o que aprendi sobre controle de versão e trabalho em equipe com Git e GitHub.

Conteúdos do curso

  • Ciclo de vida local Registrar mudanças em etapas: add, commit, log e diff.
  • Desfazendo erros Corrigir o histórico com restore, commit --amend, revert e stash.
  • GitHub e SSH Enviar e baixar código com push, pull e clone, usando chave SSH.
  • Branches, merge e rebase Trabalhar em linhas separadas e resolver conflitos na integração.
  • Trabalho em equipe Pull Requests, Code Review e Issues, que fecham com Closes #N.
  • GitHub Pages Publicar páginas estáticas na web, direto de um repositório.
