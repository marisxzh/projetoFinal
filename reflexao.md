# O que eu aprendi no curso de Git e GitHub

## O que eu aprendi

Antes do curso, eu usava o Git só no básico. Agora entendo que ele serve para organizar o trabalho, e não só para guardar código. Principais aprendizados:

- **Commits :** usar `feat`, `fix` e `docs` no começo da mensagem deixa o histórico fácil de entender.
- **Branches:** dá para trabalhar em uma tarefa sem mexer na `main`.
- **Issues e Pull Requests:** cada tarefa vira uma Issue. Eu resolvo em uma branch e junto na `main` com um Pull Request. Com `Closes #N`, a Issue fecha sozinha.
- **Repositório local e remoto:** o local fica no meu computador e o remoto fica no GitHub. Eu uso `push`, `pull` e `clone` para ligar os dois.
- **SSH:** uma chave que permite entrar no GitHub sem senha.
